### [PR Review Bot](https://github.com/yash1648) — *Python · GitHub API · LLM · Ollama*
Intelligent automated code review system that integrates with GitHub webhooks for real-time pull request analysis. Dual analysis engine: fast static heuristics (secret detection, null checks) + deep contextual LLM inference via locally hosted Ollama — fully privacy-preserving. Publishes structured review comments directly on PRs within existing GitHub workflows.

### [RustAssistant](https://github.com/yash1648) — *Rust · Whisper.cpp · Ollama · TTS*
Fully local voice assistant with zero cloud dependencies — end-to-end voice-to-response-to-speech on your own hardware. Whisper.cpp for real-time STT, Piper-TTS for natural speech, and Gemma 3.x via Ollama for intelligent conversational responses. Modular async pipeline coordinating STT → LLM → TTS with sub-900ms latency.

### [AeroShare](https://github.com/yash1648) — *Rust · LAN Networking*
Zero-config LAN file transfer tool. Discover peers and transfer files at full network speed — no internet, no cloud, no USB drives needed. Built entirely in Rust for maximum performance.

### [Library Management System](https://github.com/yash1648/LibraryManagementSystem-Hibernate) — *Java · Spring Boot · Hibernate · MySQL*
